## 核心 UI 体系

### 三栏布局

```
+--------+------------+------------------------+
| 侧边栏  |   中间栏    |      主内容区           |
| 50px   |  300px     |   flex:1 (max 1200px) |
| 可选菜单 |  时间线    |  标题 + 消息 + 分页     |
+--------+------------+------------------------+
```

移动端 `@media max-width:768px` 隐藏侧边栏和中间栏。

### 虚化时间线

中间栏内 CSS 绘制的可折叠年/月时间线：垂直虚线（`linear-gradient` 模拟）+ 年份圆点（10px 实心黑）+ 月份圆点（7px 白底边框）+ 当前月份高亮（蓝色发光）。点击年份展开/折叠 12 个月，点击月份跳转到对应页。

### 12 种消息卡片

文本（含引用预览）、图片、视频、音频（含音乐分享卡）、文件、位置（内嵌高德地图 AMap 实例）、名片（个人/公众号/企业微信）、合并转发（弹窗查看）、转账、链接卡片、小程序、视频号。

每种卡片独立 CSS：聊天气泡三角伪元素、左右对齐（自己靠右 `#9eea6a`、对方靠左 `#fff`）、系统消息居中灰色。头像 42×42px，图片 `max-width:250px`，文件/名片/小程序卡片统一 `width:220px`。

### 导航与过滤

- **分类过滤栏**：8 个按钮（全部/图片视频/文件/链接/音乐音频/交易/小程序/视频号），按类型索引筛选
- **flatpickr 日历**：自动计算有消息日期范围，禁用无消息日，选择后跳转
- **lunr.js 全文搜索**：中文分词 + 词干提取，搜索结果按时间排序，双击跳转
- **分页**：100 条/页 + 无限滚动（触顶/触底自动换页）

### 弹窗

图片模态框（全屏黑色半透明 + 居中 `max-width:90%`）、搜索模态框（60%×80% + 输入框 + 结果列表 + tooltip）、合并消息弹窗（同尺寸 + 逐条展示）。

## 数据流（Python → HTML）

1. 读取 `template.html`，在分割线处拆分为 `html_head` / `html_end`
2. 遍历消息，按类型分配到索引数组
3. 构建时间线数据结构 `timelineData[year][month]`
4. 多进程解码图片、多线程复制文件/视频、导出语音
5. 将消息 JSON 数组和时间线数据注入 HTML
6. 产出独立 `.html` 文件在浏览器中运行

## 移植要点

- 本项目用 **React + ECharts** 做应用内 GUI，不渲染 WM 的 template.html
- 仅 **HTML 导出功能** 需要参考 WM 的 CSS/JS 设计，融入 WF 的 `HtmlFormatter.ts`
- 关键复用：三栏布局 CSS、时间线虚线技法、12 种消息卡片样式、lunr.js 搜索集成
- 高德地图：WF 已有 `AMapComponent.tsx`，不需要 WM 的原始 AMap JS API 调用方式
- 详细参数（CSS 像素值、颜色码、行号）已省略，实现时直接读 WM 源文件
